# Clean Edge

Kinetic gets its proper face on macOS 26.

- **No more grey plate.** The icon now follows Apple's grid, so macOS shows it full size in the Dock, Finder and everywhere else.
- **Kinetic Agent has its logo.** You'll recognise it straight away in Accessibility, Input Monitoring and Login Items.

This is an alpha, so expect rough edges and please report what you find.
